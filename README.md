# Engelmann configurator (Nortek Hendriks)

Standalone product configurator for the Engelmann range (heat and water meters), prepared by Nortek Hendriks. Single self-contained HTML file: open `index.html` in a browser.

Online: https://nh-techsolutions.github.io/nh-configurator-engelmann/

Snapshot of 17 October 2026. Preview, not an official Engelmann tool. Technical data comes from the manufacturer's public documents; verify before ordering. Documents link to the manufacturer's official website.
